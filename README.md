# Madhu - Product Designer Portfolio (React + Vite)

A modern, responsive portfolio website built with React, Vite, and Tailwind CSS.

## Features

- ⚡ Fast development with Vite
- ⚛️ React 18 with functional components
- 🎨 Tailwind CSS for styling
- 🌙 Dark mode support
- 📱 Fully responsive design
- 🎭 Smooth animations and transitions
- 📦 Component-based architecture

## Project Structure

```
portfolio-react-app/
├── src/
│   ├── components/
│   │   ├── Hero.jsx          # Hero section with intro
│   │   ├── Footer.jsx         # Animated marquee footer
│   │   ├── About.jsx          # Services section
│   │   ├── Experience.jsx     # Work experience timeline
│   │   ├── Projects.jsx       # Case studies showcase
│   │   ├── Testimonial.jsx    # Client feedback
│   │   ├── Stats.jsx          # Statistics section
│   │   └── Contact.jsx        # Contact form
│   ├── App.jsx               # Main app component
│   ├── main.jsx              # Entry point
│   └── index.css             # Global styles & animations
├── index.html
├── tailwind.config.js
└── package.json
```

## Getting Started

### Installation

```bash
cd portfolio-react-app
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Customization

### Update Content

Edit the component files in `src/components/` to update:
- Personal information
- Services offered
- Work experience
- Projects/case studies
- Contact information

### Styling

- Tailwind configuration: `tailwind.config.js`
- Custom animations: `src/index.css`
- Color scheme can be modified in `tailwind.config.js` under `theme.extend.colors`

### Dark Mode

The site supports dark mode using Tailwind's `dark:` prefix. Toggle is handled by the `class` strategy.
